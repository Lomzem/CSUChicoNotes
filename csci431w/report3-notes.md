# Results

- Relay findings
- Make recommendations

## Qualitative

- Answers to open-ended questions
- Comments
- Order of how user navigated app
- Whether users immediately completed correctly
- Requested features
- Direct quote from participants, "participant 3 said ..."
- Positive comments were this, negative comments were this (executive summary)
- Observe common trends and why
- Don't report workflow out of context
  - This participant failed, This is why they got stuck

## Quantitative

- Whether user completed
- Task success rate: report mean/stddev
- Difficulty ratings: Use stacked bar charts, not pie charts
- ~Efficiency, time on task~

# Conclusions

- Concrete, actionable recommendations
- Don't say "we should improve the usability of it"
- Possible recommendation: We should run another user test with a second iteration of prototype, to discover **new** objectives
  - More research is needed

# Caveats

- Prototype limitations, limitations in insights
- We're all tech students
- We're all usability students
- We all have created prototypes and user tests
- All college students
- Specify all-male participants
- Age range
- Our user study is not exhaustive of all of our possible users
  - Recommendation: Could use newer study with larger sample size/demographic
